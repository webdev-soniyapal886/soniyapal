Netflix Movies & TV Shows Analysis

This project analyzes the Netflix Movies and TV Shows dataset using Python to discover trends, clean data, and create meaningful visualizations through Exploratory Data Analysis (EDA).

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings

- Cleaned and preprocessed missing values.
- Compared Movies vs TV Shows.
- Analyzed release year trends.
- Explored ratings, genres, and country-wise content distribution.
- Created visualizations to identify meaningful business insights.
