This project analyzes Walmart Store Sales data using Python to identify sales trends, store performance, seasonal patterns, holiday impact, and quarterly business growth through Exploratory Data Analysis (EDA).

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings

- Identified the store with the highest overall sales.
- Compared sales variation across all Walmart stores.
- Evaluated quarterly growth rates for Q3 2012.
- Analyzed the impact of holidays on weekly sales.
- Studied semester-wise sales trends across different years.
- Created business-focused visualizations to support decision making.
